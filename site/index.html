A cozy desktop home for your fx and opencode sessions.

A sidebar around the real terminals. Group sessions into spaces, see which ones need you, and switch between them instantly.

$ curl -fsSL https://ctrl.lucleray.me/install.sh | sh

macOS · needs fx 0.0.17+ or opencode V2 2.0.25+ · updates itself

01 · Spaces

Know what needs you

Group sessions by project. Each space can start new sessions in its own folder, with its own model and instructions. Dots tell you what's going on:

  • run finished
  • run failed
  • waiting for your answer
02 · References

Hand one session to another

Drag a session onto the terminal. ctrl pastes a mention, and the agent reads that session before it answers. No more copy-pasting context around.

03 · Resources

Every link in one place

PRs, issues, deploys, Linear tickets and Slack threads shared in a session, or across its whole space. GitHub links show live status: draft, CI, merged.

04 · Search

Find anything, fast

⌘P searches session titles and the text of every message. Hold ⌘ to see a number next to each session, then press it to jump.

05 · For agents

Let agents drive it

Agents run ctrl to look around, create spaces and sessions, start work in parallel and wait for it, read other sessions and switch what's on screen.

They also get their own checkout of any repo with ctrl worktree up: a git worktree from a pool ctrl keeps warm, released when you archive the session.

Read the CLI docs →
agent
# where am I?
$ ctrl space get self
$ ctrl session list --space self

# fan out, then wait
$ ctrl session new --title "Fix flaky test" --prompt -
$ ctrl session wait ses_7f3a…

# a fresh checkout, ready to go
$ ctrl worktree up ~/code/next.js
{ "path": "~/.ctrl/worktrees/next-js/a866" }
